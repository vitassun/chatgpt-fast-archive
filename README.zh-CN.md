# ChatGPT 快速归档

[English README](README.md)

一个适用于 Chrome 和 Edge 的轻量 Manifest V3 浏览器扩展。在 ChatGPT 左侧会话列表中将鼠标移到某个会话上，右侧会出现归档按钮；点击后立即归档，不弹确认框。

## 功能说明

- 只在 ChatGPT 左侧普通会话行上添加一个小型归档按钮。
- 调用 ChatGPT 自己的归档请求，成功后从当前列表移除该会话行。
- 不会打开会话、不弹确认框、不删除数据，也不需要 API Key。

## 使用前准备

- 必须在安装扩展的同一个浏览器配置文件中登录 ChatGPT。
- 请让 ChatGPT 左侧栏处于可见状态。按钮只会注入到侧栏中带有 `/c/<conversation-id>` 链接的可见普通会话。
- 支持 [`https://chatgpt.com/`](https://chatgpt.com/) 和旧域名 [`https://chat.openai.com/`](https://chat.openai.com/)。

## 安装（加载已解压的扩展程序）

1. 使用 GitHub 的 **Code → Download ZIP** 下载源码，或下载 Release ZIP。先完整解压，不能直接选择 ZIP 文件本身。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json`**（以及 `background.js`、`content.js`、`content.css`）的解压目录。如果文件选择器里出现多层目录，请选择最里面那个包含 `manifest.json` 的目录。
5. 打开或刷新 ChatGPT。扩展加载或重新加载后，已经打开的 ChatGPT 标签页必须刷新。

扩展没有需要配置的弹窗，也不需要工具栏按钮；所有操作都在会话行上完成。

## 首次初始化

安装完成或重新登录后，请按以下顺序操作：

1. 打开 ChatGPT 并刷新一次页面。
2. 打开任意一个普通会话并等待加载完成。这样 ChatGPT 会产生一次正常的 `backend-api` 请求，扩展才能捕获短时有效的授权请求头。
3. 返回左侧栏，尝试点击归档按钮。

不需要填写 API Key、账号 ID 或手动 Token。扩展在捕获到当前浏览器会话的授权请求头之前，不会发送归档请求。

## 日常使用步骤

1. 打开 ChatGPT；如果左侧栏收起了，先展开它。
2. 将鼠标移动到要归档的会话行上。
3. 点击该行右侧、ChatGPT 原有菜单按钮附近出现的归档图标。
4. 按钮会短暂显示忙碌状态；不会弹出确认框。
5. ChatGPT 返回成功后，该会话行会从当前列表消失。一次只处理这一行，要归档其他会话就重复以上步骤。

如果归档的是当前正在打开的会话，页面仍会保持打开，只移除左侧栏中的会话行。归档可以在 ChatGPT 的已归档会话管理页面中恢复；本扩展从不执行删除。

## 查找已归档会话

在 ChatGPT 中打开“**设置**”，进入“**已归档会话**”（或名称相近的“**管理已归档会话**”）页面。ChatGPT 更新界面后可能会调整入口名称或位置；需要时可以在那里恢复会话。

## 故障排查

### 看不到归档按钮

- 加载或重新加载扩展后，刷新 ChatGPT 页面。
- 确认左侧栏已展开，并将鼠标放在真正的会话行上；分享链接、搜索结果、项目条目或侧栏外的链接不会显示按钮。
- 在扩展页面确认选中的解压目录**直接包含 `manifest.json`**。
- 如果 ChatGPT 刚改过界面，重新加载页面再试。本扩展当前识别普通 `/c/<conversation-id>` 侧栏链接。

### 提示刷新页面或打开会话

刷新页面，打开任意一个会话并等待片刻，然后重试。这通常可以更新临时授权请求头；同时确认 ChatGPT 登录没有过期。

### 请求失败或超时

刷新后再试一次。后台请求最长等待 15 秒，页面消息最长等待 18 秒。如果仍然失败，请重新登录，暂时禁用会修改 ChatGPT 侧栏的其他扩展，并在支持的域名中对普通会话重试。

### 点击后会话行仍然存在

等待请求完成后刷新页面。只有 ChatGPT 返回 HTTP 200 或 204 时才会在本地移除会话行；失败请求不会被当作成功处理。

## 更新或卸载

- **更新：** 用新版本文件替换解压目录中的文件，在扩展页面点击本扩展的“重新加载”，然后刷新 ChatGPT 标签页。
- **卸载：** 打开扩展页面，找到“ChatGPT 快速归档”，点击“移除”。卸载扩展不会改变已经归档的会话。

## 隐私与权限

- 扩展只运行在 `chatgpt.com` 和 `chat.openai.com`。
- `webRequest` 仅用于读取 ChatGPT 自己的 `backend-api` 请求中的 `Authorization` 和可选 `chatgpt-account-id` 请求头。每条凭据最多保留 30 分钟，然后从 `chrome.storage.session` 和扩展内存中清除；不会发送到第三方。
- 扩展后台向当前 ChatGPT 域名的 `/backend-api/conversation/<id>` 发送归档请求，请求体为 `{ "is_archived": true }`。
- 后台请求禁止重定向，只接受 200 或 204，并拒绝 HTML 响应；扩展不会调用删除接口。

## 已知限制

- ChatGPT 的页面结构和内部接口可能变化。如果侧栏改用不同的会话链接格式，按钮可能暂时不显示。
- 当前只处理侧栏中普通的 `/c/<conversation-id>` 会话链接，不处理分享链接、项目链接、搜索结果或页面其他位置的会话引用。
- 扩展一次只归档一个会话，不提供批量归档、删除或撤销按钮。
- 归档后的会话仍可通过 ChatGPT 自带的已归档会话入口恢复，具体取决于 ChatGPT 账号和工作区策略。
